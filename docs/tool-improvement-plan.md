# Lumen Tools 全量 Bug 修复与功能优化清单

> 审计范围：`src/tools/registry.ts` 注册的 88 个工具页面，以及首页、工具页壳层和共用编辑器。  
> 审计基线：2026-08-05。本文既记录本次已完成的修复，也作为后续迭代的验收清单。

## 1. 本次已完成（P0）

- [x] 首页工具目录支持列表 / 网格布局切换，并保存本机偏好；移动端继续保持单列可读性。
- [x] 共用 `EditorPanel` 修复文本域原生拖拽尺寸：编辑器不再用弹性高度吞掉 resize，双栏、单栏和转换类页面统一生效。
- [x] JSON 工作台沿用共用编辑器修复，并保留格式化、压缩、清空和校验状态。
- [x] JSON 差异比较改为“左右输入 + 下方结果”的稳定布局；增加格式化两侧、交换输入、行号、增删统计、上下文行和复制差异结果。
- [x] 颜色转换改为可见的饱和度/明度色盘，增加色相与透明度滑杆、棋盘格预览，支持 `#RGB`、`#RGBA`、`#RRGGBB`、`#RRGGBBAA`、RGBA 和 HSLA 输出。
- [x] 完成 88 个注册工具的页面级审计，清单见下表。

## 2. 共性问题与实施顺序

| 优先级 | 范围 | Bug / 机会 | 建议方案 | 验收标准 |
| --- | --- | --- | --- | --- |
| P0 | 所有 `EditorPanel` 页面 | 文本域 resize 体验不一致 | 统一使用共用编辑器样式；输入和输出都允许垂直调整，移动端不溢出 | 双栏两侧均能拖动高度；窄屏无横向滚动 |
| P0 | 首页 | 工具数量多，纵向列表扫描成本高 | 列表/网格切换，保留筛选和分类状态 | 两种视图可切换、刷新后偏好仍在、空结果可恢复 |
| P0 | JSON Diff | 三个编辑器直接进入双栏网格，结果错位 | 结果独立成区，采用行号、标记色和统计摘要 | 修改一行即可定位新增/删除；无效 JSON 有明确错误 |
| P0 | 颜色转换 | 原生色盘不可见、只支持 6 位 HEX、没有 Alpha | 自绘 SV 色盘 + Hue/Alpha 控件 + 透明棋盘 | 点击/拖拽、键盘滑杆、透明色预览和可复制值一致 |
| P1 | 所有输出型工具 | 结果为空时的状态不统一 | 统一空态、错误态、复制按钮和成功反馈 | 用户能区分“未运行”“无结果”“输入错误” |
| P1 | 所有转换工具 | 多数输入修改后不会自动清理错误或缺少运行提示 | 统一“自动预览 / 手动运行”策略，并显示处理范围 | 输入变更后的行为在标题和状态栏中明确 |
| P1 | 图片/摄像头工具 | 权限、超大文件和导出失败缺少恢复路径 | 增加权限拒绝、尺寸限制、释放 URL 和导出错误提示 | 取消授权、重复导入、切换页面后无资源泄漏 |
| P2 | 参考类工具 | 数据来自静态内置样本，搜索能力有限 | 抽取数据源、增加分类/复制/键盘导航 | 搜索命中、无结果、复制状态一致 |
| P2 | 安全类工具 | 生成/加密结果的风险提示深度不一 | 增加参数说明、随机源/算法说明和清空入口 | 不把演示工具误解为生产密钥管理器 |

## 4. 回归测试矩阵

- [ ] 首页：全部/分类/关键词筛选分别验证列表和网格；刷新后布局偏好保持。
- [ ] 编辑器：JSON 工作台、Base64、URL、JWT、Hash、所有 `dual-editor` 页面分别拖动左右文本域；验证窄屏和全屏模式。
- [ ] JSON Diff：相同 JSON、键值修改、数组增删、嵌套对象、空对象、无效 JSON、超长行、交换输入。
- [ ] 颜色：色盘点击与拖动、Hue、Alpha、`#RGB/#RGBA/#RRGGBB/#RRGGBBAA`、非法输入、明暗主题、移动端。
- [ ] 图片：重复导入、取消权限、透明 PNG、导出下载、全屏退出和浏览器返回。
- [ ] 通用状态：空输入、错误输入、复制按钮、键盘 Tab/Enter、`prefers-reduced-motion`。
- [ ] 质量门槛：`npm run build`、`npm run lint`，并在 Chromium 及移动视口完成一次手动冒烟。
